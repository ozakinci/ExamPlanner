# ExamPlanner

A free, no-login study schedule generator for exam periods.

Built to help parents and students create a draft study plan, which can be downloaded 
as a color-coded Excel file and fine-tuned as needed.

## How it works
1. Set your study period start date and available hours per day of the week
2. Add subjects with their exam dates and a color
3. Click Generate — the planner automatically distributes study sessions weighted 
   by exam proximity, ensuring each subject gets proportional attention
4. Download as .xlsx — opens directly in Excel or LibreOffice with full color coding 
   and working formulas

## Features
- Weighted auto-scheduling: subjects with earlier exams get priority, 
  but later exams still get adequate preparation
- Night-before rule: the evening before any exam is always reserved for that subject
- Sortable summary table per subject (sessions, hours, exam date)
- Color-coded Excel export with live SUM formulas
- Everything runs in the browser — no data is sent anywhere, no account needed

## Usage
Open the app: https://ozakinci.github.io/ExamPlanner
No installation or account required — runs entirely in your browser.
